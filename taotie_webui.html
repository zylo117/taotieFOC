说明：脉冲数就是实际下发给驱动器的 STEP 个数，1 个 STEP = 1 个微步， 与驱动器当前微步设置一致（一圈 = 200 × 微步数，默认 64 细分 = 12800）。波形图的 “理论累计行程”也是按这个口径换算的，不再沿用过去那套“固定 256 细分 / 51200 一圈”的说法。
编码器滤波窗口：0 = 关闭滤波（噪声最大、零滞后）。 窗口 = 4（默认）正好盖住一个控制周期内的 4 次喷发采样 （SPI 7.8MHz，每次 2.05µs，总跨度 8.2µs）， 每拍整个替换一遍，所以没有跨周期历史、也没有群延迟。 填大于 4 就会开始跨控制周期（每超 1 多 2.05µs 历史）， 跟随误差会随之变大，不建议。改完下发约 1 秒后才生效。 SPI 已实测上限：7.8MHz；再高到 15.6MHz 会因 MISO 建立时间不足而角度错乱。
STEP 输入脚固定用内部下拉（约 40k），悬空时不会乱跳，推挽驱动可直连。 若改接开漏 / 源极跟随这类弱驱动，需要在 pulse_capture.cpp 里把 PULSE_CAPTURE_INPUT_PULL_DOWN 置 0（编译期开关）后重新烧写。

单线 UART 说明：
常见 USB-TTL 适配器通常没有真正的单线半双工支持；多数场景下推荐使用双线 TX/RX + GND。只有特定硬件或 MCU 端口支持 开漏 / 半双工单线模式时，才可工作。若你用的是标准 CH340 / CP2102 / FT232，通常需要双线模式。

位置 PID

超前校正系数（0x15C）：1.0 = 不启用。补回微分低通吃掉的相位裕度，范围 1.0~5.0；需配合 Kd>0 才有作用。不存 Flash，重启后回到 1.0。
【单位】输入=误差（圈）× Kp = 输出附加速度（转/秒）。Kp=60 表示 1° 误差给 0.167 转/秒（10RPM）。两个环的输出都在固件里限幅到规划速度的 30%/20%，所以填大了也不会打穿速度指令。

速度 PID

【单位】增益就是“转/秒 误差 → 转/秒 修正”，无量纲。0.3 表示 1RPM 误差给 0.3RPM 修正；旧固件这里有个隐藏的 ×0.01，所以当年的 30 等于现在的 0.3。Kd 作用在实测加速度上（微分先行），不是误差微分。

三种模式共用一组参数

角度伺服 / 规划运动 / 外部脉冲跟随都用上面那一组（0x129~0x12E）。
角度模式的转速由 0x12F/0x130 的梯形轮廓决定，Kp 只管跟踪刚度与抗扰， 不再决定跑多快。写废弃的 0x156~0x15B 会在串口提示。

滞后角模型（可调，存 Flash）

加速时转子要多落后 ΔL ≈ c·a（物理上来自 J·a/k_t），c 就是上面这个系数： 1 表示 600RPM/s 时多算 0.6°。把它建模掉，就不会把"加速必然的滞后" 当丢步补掉（那会让末端多转）。
死区要和"滞后角表有多准"匹配：表是带载标的、负载变了就调大；重新标定后再收小。 两个值都随「写入参数到 Flash」保存。
写 0x155=1：串口输出一次速度环诊断（跟踪误差 err / P、I、D 分量 / 前馈 ff / web 与 live 增益对比），打完自动清零；固件刻意不做周期打印，因为 23ms 的 printf 会干扰被诊断的闭环本身。
